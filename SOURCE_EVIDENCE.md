## Public-repository decision

The raw PDF is not republished here. It contains student identification numbers and screenshots/environment context that are unnecessary for public recruiter review.

Instead, the repository preserves:

- verified numerical results,
- technical summaries,
- sanitized code/workflow reconstructions,
- explicit consistency notes,
- attribution and limitations.

## Evidence quality

The strongest evidence in the report is the combination of code excerpts, measured throughput table, terminal screenshot, plotted output, and PCAP/Wireshark screenshots.

The portfolio does not silently promote narrative statements into stronger implementation claims when the retained snippets do not show them directly.
