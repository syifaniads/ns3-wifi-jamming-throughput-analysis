## Attribution policy

This was collaborative Project Based Learning work. The portfolio repository therefore does **not** claim that Syifani individually authored every original code block, capture, graph, or report section.

The public framing follows this evidence hierarchy:

1. **Member names** — verified from the retained report.
2. **Syifani's Group Lead role** — recorded from the portfolio owner's direct project-context confirmation.
3. **Technical implementation/results** — only claimed when supported by retained report text, code excerpts, tables, or screenshots.
4. **Reconstructed examples** — clearly labeled as sanitized reconstructions rather than original source recovery.
